## `demo run DEMO-02-infrastructure` (live)

PATH augmented with `artifacts/win-x64/` so the inner `nexus infrastructure ...`
calls resolve. `NEXUS_VMS_YAML` set for the inner invocations:

```text
> nexus demo run DEMO-02-infrastructure
── ● GREEN  ok  demo run DEMO-02-infrastructure  (2026-05-14 ...)  total NN.NNs ──
| # | Exit | Duration | Command                                  |
| 0 | 0    | M.MMs    | nexus infrastructure list                |
| 1 | 0    | M.MMs    | nexus infrastructure status foundation   |
```

Each step ran the v0.2 infrastructure verb; both exited 0 against the
live VMware fleet. The runner correctly observed `infrastructure list`
emitting 81 VMs and `infrastructure status foundation` showing 8 nodes
with state-decoration.

## `demo record DEMO-02-infrastructure` (vhs not installed)

```text
> nexus demo record DEMO-02-infrastructure --output-dir .\out
── ● YELLOW  tape written; vhs unavailable  demo record ... ──
  tape           : .\out\DEMO-02-infrastructure.tape
  vhs hint       : vhs not found on PATH. Install from https://github.com/charmbracelet/vhs (winget install charmbracelet.vhs / brew install vhs / scoop install vhs) or set NEXUS_VHS_PATH to an absolute path.
exit=1
```

The `.tape` file is written to disk regardless. Operators with `vhs`
installed get exit 0 + the rendered GIF path; without vhs, they get
exit 1 + the install hint + the tape file they can render manually
later.

Generated `.tape` shape (excerpt):

```text
# Generated by nexus-cli demo record for DEMO-02-infrastructure
# VM fleet inventory + per-cluster status
Output .\out\DEMO-02-infrastructure.gif
Set FontSize 14
Set Width 1200
Set Height 800
Set Padding 20
Sleep 1s
Type "nexus infrastructure list"
Enter
Sleep 4s
Type "nexus infrastructure status foundation"
Enter
Sleep 4s
```

## Negative paths

| Case | Result |
|---|---|
| `demo list` with no demos found | exit 0, hint message "(no demos found. Set NEXUS_DEMOS_PATH or place <id>.json files under ./docs/demos/.)" |
| `demo run BOGUS-ID` | exit 2, `unknown demo 'BOGUS-ID'. Known: DEMO-01-cluster-status, DEMO-02-infrastructure` |
| Step exits non-zero (e.g., command typo) | exit 1, report's first-failed-step stderr tail is printed |
| Step exceeds 5-min step timeout | step exit -1, status `step failed` |
| Top-level Ctrl-C during a long step | status `aborted`, exit 3 |
| `demo record` with vhs unavailable | exit 1, tape on disk, hint message present |

## Open follow-ups

- **Playwright bridge** for web-UI demos. Deferred to v0.4.x; Playwright
  is AOT-hostile and would likely push past the 25 MB exit gate.
- **`demo record --all`** to render every demo in the catalog (useful
  for CI-driven release-asset GIFs once we have enough demos).
- **`--mode dry-run`** for CI: type commands into the recording without
  actually executing them. Lets CI produce GIFs without Vault auth.
- **More demos.** Currently 2 (cluster-status + infrastructure). Adding
  one per failover-test scenario (3 more) would round the catalog out
  nicely. Track for v0.4.x.
