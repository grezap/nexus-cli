## Live-caught bugs (3, all fixed in source)

1. **cert-rotate didn't rotate** — `pkiCert` persists + reuses the leaf across vault-agent restarts (serial unchanged). Fixed: `cp -a`+`rm` the bundle (with `.bak` restore safety) to force `pkiCert` to re-issue, then restart the agent + service. Serials then change on all 6.
2. **acl grant failed** — `consul acl token create` refuses a policy-less token. Fixed: attach `-templated-policy builtin/dns`; revoke uses `-accessor-id`.
3. **chaos cancelled before output** — the recovery loop's full-status poll (Portainer HTTP timeout each cycle) blew the command's `Duration+60 s` budget. Fixed: lightweight `docker node ls` recovery poll (victim Ready+Active), 60 s deadline.

**Infra finding (not an adapter bug):** the Vault KV Portainer admin `plaintext` does not authenticate against the running Portainer (`/api/auth` → "Invalid credentials") → the `topology` `/api/endpoints` enrichment degrades to a version-only label. Tracked separately.
