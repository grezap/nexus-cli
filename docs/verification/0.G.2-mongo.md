## What shipped

`MongoAdapter` (`src/Nexus.Cli.Adapters/Cluster/MongoAdapter.cs`) implements all of
`IClusterAdapter` via SSH-shell-out to on-node `mongosh` / `mongodump` / `mongorestore` (no managed
MongoDB driver). It authenticates as the dedicated **`nexus-cluster-admin`** operator user, whose
password it fetches at runtime from **Vault KV** via the framework's optional `INexusVaultClient`
(plumbed through `ClusterBootstrapper` this release; Redis/Kafka unaffected). Chaos reuses the
embedded `Cluster/Resources/nexus-chaos.sh`.

## The credential model (ADR-0011)

- Operator identity **`nexus-cluster-admin`** = `clusterMonitor + clusterManager + backup + restore
  + userAdminAnyDatabase` on `admin` — least privilege covering the full verb surface, **not** the
  root-equivalent `__system`/keyFile identity.
- Password lives **only** in Vault KV (`nexus/oltp/mongo/operator-password`); never on nodes. The
  adapter fetches it via `VAULT_ADDR`/`VAULT_TOKEN`/`VAULT_CACERT`; the one-time IaC createUser
  bootstrap reads it via the node's own Vault Agent token. Infra: seed overlay
  (`role-overlay-vault-mongo-operator-user-seed.tf`) + agent-policy v3 + createUser overlay
  (`role-overlay-mongo-operator-user.tf`) — all proven in the cold-rebuild apply graph below.

## Bugs caught + fixed by live-verify (the headline lesson — unit tests can't catch these)

1. **`--eval` single-quote mangling** — the remote shell wraps `--eval '<js>'` in single quotes, so
   JS string literals using single quotes (`print('REMOVE_OK=')`) terminated the shell quote and
   produced `SyntaxError`. Fixed: **all** embedded JS uses double-quoted literals.
2. **`mongodump` dumped 0 app docs** — twice. (a) the dump URI's `/admin` database path *scoped* the
   dump to admin system collections; fixed by targeting `/nexus_smoke?...&authSource=admin`. (b) a
   `readPreference=secondary` dump returned 0 documents against this RS; fixed by reading from the
   PRIMARY (default).
3. **`mongorestore` ns-remap restored 0 docs** — `--nsFrom`/`--nsTo` rename but don't *select*;
   **`--nsInclude 'nexus_smoke.*'`** is required first. Fixed → round-trip restores the doc.
4. **`backup restore` couldn't find a node-local archive** — backups are node-local on the SECONDARY
   that ran the dump; restore now discovers which node holds the archive and runs there.
