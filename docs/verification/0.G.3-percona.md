## What shipped

`PerconaAdapter` (`src/Nexus.Cli.Adapters/Cluster/PerconaAdapter.cs`) implements all of
`IClusterAdapter` via SSH-shell-out to on-node `mysql` (PXC backends + the ProxySQL `:6032` admin
interface) + `mysqldump` (no managed MySQL driver). It authenticates as the dedicated
`nexus-cluster-admin` MySQL user (ALL PRIVILEGES WITH GRANT OPTION); that password + the ProxySQL
admin password come from **Vault KV** via `INexusVaultClient` (ADR-0011 model, unchanged framework).
Registered in `ClusterBootstrapper`.

## Two control planes (ADR-0012)

- **Cluster state** = `SHOW STATUS LIKE 'wsrep_%'` on each PXC node (synchronous multi-primary).
- **Routing state** = ProxySQL admin `runtime_mysql_servers` — `mysql_galera_hostgroups` keeps ONE
  writer (hostgroup 10, ONLINE), the rest as backup_writer (20) / reader (30); demotes non-Synced to
  offline (40). The adapter maps a PXC node's role from its ProxySQL hostgroup; the writer = leader.

## Bugs caught + fixed by live-verify (the headline lesson)

1. **ProxySQL `SHUNNED` rows read as writers** — a node lingers in the writer hostgroup (10) as
   `SHUNNED` while it actually serves from backup_writer (20). The first read ignored `status` → all
   3 nodes looked like the writer. Fixed: only count `ONLINE` rows; pick the lowest hostgroup where
   the node is ONLINE.
2. **`"inactive".Contains("active") == true`** — the `scale-out add` node-discovery used a substring
   check, so a *stopped* (unjoined) node read as "joined" → "all nodes already joined". Fixed with an
   exact `is-active` prefix match (the [[powershell-match-substring]] lesson, C# edition). Same trap
   fixed in the ProxySQL liveness checks.
3. **PXC `strict_mode=ENFORCING` prohibits `LOCK TABLES`** — mysqldump emits explicit
   `LOCK TABLES … WRITE` around INSERTs by default, which the restore rejects (`ERROR 1105`),
   aborting before the INSERT (0 rows restored). Fixed: dump with `--skip-add-locks --no-tablespaces`
   (+ `--single-transaction` for a consistent snapshot); restore strips `USE`/`CREATE DATABASE` and
   pipes the unqualified DDL/DML into a verify schema (no fragile sed-rename).
4. **(infra) galera-bootstrap `sed -e '$a\'`** — the overlay's newline-ensure had its `$a` eaten by
   PowerShell `@"..."@` interpolation → "sed: missing command", which failed the from-zero apply.
   Replaced with a `printf '\n…\n'` append (no `$`).
